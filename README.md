# Powerflow Chiropractic — [chiro](https://github.com/ggpt844-art/chiro)

Next.js marketing site for Powerflow Chiropractic (Dr. Sandy Bhasin), Mississauga ON.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Learn more

- [Next.js Documentation](https://nextjs.org/docs)

## Deploy

Deploy on [Vercel](https://vercel.com/new) or any Node host that supports Next.js.
